# E-commerce Customer Analytics

## Project Overview

An interactive e-commerce analytics project developed to analyze customer behavior, order performance, revenue, purchasing patterns, and customer segments.

The project transforms e-commerce transaction data into actionable customer and business insights through data cleaning, validation, KPI analysis, and Power BI visualization.

## Business Objectives

- Analyze customer purchasing behavior
- Monitor order and revenue performance
- Identify customer segments
- Understand purchasing patterns
- Evaluate sales performance
- Monitor key e-commerce KPIs
- Support customer-focused business decisions

## Dataset

The project uses a synthetic e-commerce dataset containing approximately 10,000 transaction records.

Key fields include customer information, order details, product information, regional information, payment details, monthly charges, and delivery information.

## Data Preparation

Data preparation included:

- Duplicate identification and removal
- Missing-value validation
- Data type validation
- Date format standardization
- Text consistency checks
- Numerical field validation
- Final data quality validation
